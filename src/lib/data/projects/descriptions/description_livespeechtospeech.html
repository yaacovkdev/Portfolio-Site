Upon looking at publically available live translator services, it was hard to find a reliable translator that would get live audio, and speak back translations in various natural voices. Google Translate has this feature too but the amount of natural voices and the speed at which it decides to break down the sentences to speak back seems limited and unconfigurable at the moment. This program allows users to configure existing FasterWhisper and KokoroTTS with option to use Google Translate service or local Whisper translator, producing more refined results. If you have a machine with an NVIDIA GPU you can run this program. This is still a prototype and is subject to future improvements as well as potential updates or rewrites of entire modules. We are looking for a way to refine the system for it to be as responsive and accurate as local resources allow, in order to serve others.
